# Second Report Generation Instructions

## Objective
Create a new research report using:
1. Content and citations from the first report
2. Additional insights from newly downloaded PDFs
3. Proper citation continuity and expansion

---

## Input Sources

### Existing Sources
- Located in: `/existing_pdfs`
- Previously cited in: `first_report/report_v1.pdf`
- Citation file: `citations_v1.bib`

### New Sources
- Located in: `/downloaded_pdfs`
- Must be analyzed and cited separately
- Add to updated citation database

---

## Requirements

1. Preserve all valid citations from first report.
2. Do NOT remove existing references unless invalid.
3. Add new citations sequentially.
4. Avoid duplication of references.
5. Merge overlapping concepts instead of rewriting redundantly.
6. Maintain consistent academic tone.
7. Update literature review section to include new materials.

---

## Output

- `report_v2.pdf`
- `citations_v2.bib`
- `change_log.md`
