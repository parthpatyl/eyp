# Citation Management Rules

## Existing Citations
- Keep numbering intact if numeric style is used.
- If author-date style, preserve original keys.

## New Citations
- Add after existing ones.
- Format consistency required (APA / IEEE / etc).
- Validate:
  - Author names
  - Year
  - DOI
  - Publisher

## Deduplication Rules
If new PDF already exists in previous citation database:
- Merge entries.
- Do not create duplicate reference keys.

## Reference Naming Convention

Old:
    Smith2022a

New:
    Johnson2024a

Avoid:
    ref1, ref2 (non-descriptive keys)
